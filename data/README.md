# data/

Everything under here is downloaded or generated by the pipeline and is
git-ignored; only this skeleton is committed so a fresh clone has the layout
the code expects.

    raw/                inputs, fetched by `step2-download`
      admin/            geoBoundaries ADM1 units
      dem/              Copernicus GLO-30 / GLO-90 tiles
      exposure/         OSM settlements and roads (Overpass cache)
      glim/             GLiM lithology (only if calibration_regions is used)
      inventory/        landslide inventories: roback/, farwest/, sikkim/
      landcover/        ESA WorldCover (only if calibration_regions is used)
      worldclim/        WorldClim v2.1 monthly precipitation
      worldclim_future/ downscaled CMIP6 scenarios
    work/               warped grids and intermediates, keyed to run name and
                        resolution; safe to delete, everything is rebuilt
